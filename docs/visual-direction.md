# Little Hero Visual Direction

## Core feel

Little Hero should feel like a soft illustrated picture book, not a productivity app.

The child should feel:

> I am helping my world become better.

The parent should feel:

> This lowers after-school conflict and creates a predictable ritual.

## Current visual language

- Cream base background
- Soft glass-like cards
- Large rounded task cards
- Pastel theme worlds
- Gentle character feedback
- Completion progress as world restoration

## Avoid

- Dense dashboards
- Cold blue SaaS UI
- Small buttons
- Gray admin panels
- Adult productivity language
